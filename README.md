# Real Promo Club — Grupo WhatsApp

Landing page mobile-first para entrada no grupo de WhatsApp do Real Promo Club.

## Estrutura
- `index.html`: conteúdo e SEO básico.
- `styles.css`: visual responsivo e animações sutis.
- `favicon.svg`: favicon leve em SVG.

A página usa apenas conteúdo fornecido pelo projeto e não inclui prova social, números, descontos ou produtos inventados.
